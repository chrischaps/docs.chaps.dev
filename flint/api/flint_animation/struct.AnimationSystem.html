Struct AnimationSystem 

Source 
pub struct AnimationSystem { /* private fields */ }
Expand description

Top-level animation system integrating clip playback with the ECS world.

Supports property tweens (Tier 1), skeletal animation (Tier 2), node animation (Tier 3), and sprite sheet animation (Tier 4). Implements RuntimeSystem, bridges TOML components via the various Sync types.

pub fn seek_sequence( &mut self, world: &mut FlintWorld, entity_id: EntityId, t: f64, step_dt: f64, ) -> usize

Seek an entity’s sequence to t by deterministic replay: reset the skeletal state, restart the sequence, and step sequence + skeletal tiers together in step_dt increments. The caller must first restore the animator component to its pre-sequence state (the sequence only ever adds writes). Cues fired during the replay are discarded. Returns the number of events fired.
