Expand description

An emitter as authored (asset or inline component).

Every field has a default so partial tables load. Legacy inline keys (lifetime_min/lifetime_max, speed_min/speed_max, scalar size_start/size_end, color_start/color_end, burst_count, shape = "cone" + shape_radius/shape_angle/shape_extents) are accepted and folded into the modern fields by resolve.
