Resolved runtime emitter configuration.

§name: String§emission_rate: f32§emission_per_meter: f32§max_particles: usize§lifetime_min: f32§lifetime_max: f32§duration: f32§looping: bool§start_delay: f32§autoplay: bool§playing: bool§bursts: Vec<Burst>§shape: EmissionShape§shape_offset: [f32; 3]§shape_axis_u: [f32; 3]

Optional orientation for the box shape: extents.x runs along u, extents.y along v, extents.z along u × v. Both zero keeps the axis-aligned box (ADR 0061).

§shape_axis_v: [f32; 3]§local_axes: bool

Rotate direction, shape_offset and shape axes by the emitter’s world rotation (and scale distances by its scale). Inline components default to false for ADR 0061 compatibility; assets default to true.

§speed_min: f32§speed_max: f32§direction: [f32; 3]§spread: f32§gravity: [f32; 3]§damping: f32

Exponential velocity decay per second.
