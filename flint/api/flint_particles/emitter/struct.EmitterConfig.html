Configuration parsed from a particle_emitter TOML component

Fields§

§emission_rate: f32§burst_count: u32§max_particles: usize§lifetime_min: f32§lifetime_max: f32§speed_min: f32§speed_max: f32§direction: [f32; 3]§spread: f32§gravity: [f32; 3]§damping: f32§size_start: f32§size_end: f32§color_start: [f32; 4]§color_end: [f32; 4]§texture: String§stretch: f32

Velocity-aligned billboard stretch (s): quad half-length grows by |velocity| * stretch / 2 along the screen-projected velocity. 0 disables (normal camera-facing quads). Rain streaks: ~0.03.

§frames_x: u32§frames_y: u32§animate_frames: bool§blend_mode: ParticleBlendMode§shape: EmissionShape§shape_offset: [f32; 3]

Spawn-region translation relative to the emitter position (ADR 0061: lets a script park the region on one side of a body). Default zero.

§shape_axis_u: [f32; 3]

Optional orientation for the box shape: extents.x runs along u, extents.y along v, extents.z along u × v. Both zero (default) keeps the legacy axis-aligned box verbatim.
