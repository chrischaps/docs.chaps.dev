flint_particles

Module sync 

Source
Expand description

Bridges ECS particle_emitter / particle_effect components to the simulation, and packs alive particles for the GPU.

Instances live in BTreeMaps keyed by entity or detached handle, so iteration — and therefore draw order and RNG consumption — is deterministic frame to frame and run to run (ADR 0068).
