Expand description

kira, set up as flint_audio::AudioEngine sets it up on the desktop (a low-pass on the main track, music and SFX buses under it), driven by commands instead of calls.

Fields§

§errors: u32

Commands that failed (an unknown id, a full track, an unreadable batch). The processor reports the count with its buffer stats.
