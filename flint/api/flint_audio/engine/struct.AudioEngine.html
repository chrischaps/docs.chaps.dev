Struct AudioEngine

pub struct AudioEngine { /* private fields */ }
Expand description

Wraps Kira’s AudioManager with sound caching and listener management

Implementations§

impl AudioEngine

Source

pub fn new() -> Self

An engine with sound. On the desktop it opens the default device now (silent if there is none). In the browser it stays silent until start is called from a user gesture, since an AudioContext made before one is kept suspended.

Source

pub fn silent() -> Self

An engine that loads and caches sounds but plays none until start.

Source

pub fn start(&mut self) -> bool

Open the audio device, if it isn’t open, and say whether there is sound. In the browser, call it from the click (or key) handler that begins the game: it opens the worklet’s AudioContext inside the gesture, and the worklet’s mixer starts a moment later, with the calls made meanwhile waiting for it. Failing leaves the engine silent, as before, and a later call tries again.

Source

pub fn start_remote(&mut self, link: Link)

Mix somewhere else: every call from now on is written to link, and the sounds cached so far are sent along it. The browser’s worklet is one end; a test can take the outbox itself.

Source

pub fn poll(&mut self)

Once a frame: follow the mixer. In the browser this notices the worklet running (and lets go of the main thread’s copies of the sounds it holds) or failing, in which case the main thread takes over and take_restarted says so.

Source

pub fn take_restarted(&mut self) -> bool

Whether the mix moved since the last call, losing everything that was playing: the caller starts its sounds again.

Source

pub fn mixer_name(&self) -> &'static str

Where the sound is mixed: “worklet” (starting or running), “main thread”, or “silent”.

Source

pub fn buffer_stats(&self) -> Option<BufferStats>

How steadily the browser’s audio stream has been fed since it opened: buffers, late ones, slack and mix time. None on the desktop, and before start.

Source

pub fn set_bus_volume(&mut self, bus: Bus, volume: f64)

Set a mixer bus volume (linear amplitude, 0.0 = mute, 1.0 = unity). Applies multiplicatively on top of per-sound volumes, so script-driven fades keep working underneath.

Source

pub fn set_held(&mut self, held: bool)

Hold the mix (FlintKart#27): both buses fade out and stay out, under any volume set meanwhile, and come back to it when let go. Sounds keep their places, so a loop resumes where the game left it.

Source

pub fn is_held(&self) -> bool

Whether set_held holds the mix.

Source

pub fn is_available(&self) -> bool

Whether audio is actually available

Source

pub fn is_remote(&self) -> bool

Whether the mix runs elsewhere (the browser’s worklet), which says nothing back about what it plays.

Source

pub fn manager_mut(&mut self) -> Option<&mut AudioManager<AudioBackend>>

Mutable access to the underlying kira manager, for hosts that start additional clocked content (the music suite) on the same device stream. Handles created on it must drop before this engine (ADR 0017). None while silent, and when the mix runs in the browser’s worklet.

Source

pub fn load_sound(&mut self, name: &str, path: &Path) -> Result<()>

Load a sound file into the cache

Source

pub fn queue_sound(&mut self, name: &str, path: &Path, need: Need) -> Result<()>

Queue a sound file to be decoded over the next frames by decode_queued, instead of now: a song takes 100 to 241 ms to decode in the browser. The file is read now. A sound already cached is left alone, and one already queued keeps its place unless need is sooner.

Source

pub fn decode_queued(&mut self, budget: Duration) -> usize

Decode queued sounds for up to budget, soonest needed first, and cache the ones that finish. Call once a frame; it costs nothing when the queue is empty. Returns how many are still queued.

Source

pub fn is_queued(&self, name: &str) -> bool

Whether a sound is waiting in the decode queue.

Source

pub fn queued_count(&self) -> usize

How many sounds are waiting in the decode queue.

Source

pub fn load_sound_from_bytes( &mut self, name: &str, bytes: Vec<u8>, ) -> Result<()>

Cache an encoded sound held in memory (WAV, OGG, FLAC or MP3 bytes, e.g. from include_bytes!) under name. Replaces any sound already cached under that name; sounds already playing keep the old data.

Source

pub fn load_sound_from_samples( &mut self, name: &str, sample_rate: u32, channels: &[&[f32]], ) -> Result<()>

Cache a sound made in memory under name, from its samples: one channel (played on both sides) or two (left, right), each in -1..1 at sample_rate Hz. Unequal channels are cut to the shorter. Replaces any sound already cached under that name.

Source

The listener’s ears, for working out a placed sound’s gains (crate::pan). Before there is a listener, where AudioSystem first puts it.

Whether the listener has been created

pub fn create_spatial_track_with( &mut self, position: Vec3, (min_distance, max_distance): (f32, f32), rolloff: f32, bus: Bus, ) -> Result<SpatialTrack>

Create a spatial track with its own falloff curve (see DEFAULT_ROLLOFF).

pub fn play_on_spatial_track( &mut self, sound_name: &str, track: &mut SpatialTrack, volume: f64, pitch: f64, looping: bool, ) -> Result<SoundHandle>

Play a cached sound on a spatial track (looping or one-shot)

Source

pub fn play_non_spatial( &mut self, sound_name: &str, volume: f64, pitch: f64, looping: bool, bus: Bus, ) -> Result<SoundHandle>

Play a cached sound on a mixer bus (non-spatial, e.g. ambient/music)

Source

pub fn play_panned( &mut self, sound_name: &str, volume: f64, pan: f32, pitch: f64, looping: bool, bus: Bus, ) -> Result<SoundHandle>

Play a cached sound on a mixer bus, panned (kira’s Panning: -1 left, 1 right, at constant power). A placed sound plays this way with its gains from crate::pan, steered every frame (#138).

Source

pub fn play_at_position( &mut self, sound_name: &str, position: Vec3, volume: f64, pitch: f64, ) -> Result<()>

Play a one-shot sound at a 3D position. Its handle is kept until the sound finishes playing.

Source

pub fn play_oneshot_at( &mut self, sound_name: &str, position: Vec3, volume: f64, pitch: f64, distances: (f32, f32), rolloff: f32, bus: Bus, ) -> Result<()>

Play a one-shot at a 3D position with its own falloff, (min, max) metres from the listener: full volume within min, silent past max, along the curve rolloff (see DEFAULT_ROLLOFF). Routed through bus.

Source

pub fn pan_oneshots(&mut self)

Steer placed one-shots to where the listener is now. Call once a frame, after update_listener.

Source

pub fn set_old_mix(&mut self, old: bool)

Mix as before #138, for comparing (the web’s ?mix=old): placed one-shots on kira spatial tracks, none skipped or stolen. Sounds already playing keep the way they started.

Source

pub fn old_mix(&self) -> bool

Whether set_old_mix is on.

Source

pub fn cleanup_finished_oneshots(&mut self)

Remove finished one-shot spatial sounds. Call once per frame. (A remote mixer sweeps the old mix’s own.)

Source

pub fn mix_counts(&self) -> Option<MixCounts>

What the mixer holds, for the perf readout: every voice and spatial track kira holds here; in the browser’s worklet, which says nothing back, the one-shots this engine started. Which of the audio_sources’ are paused, and the worklet’s other voices, are AudioSync::add_mix_counts’s to say. None without a device.

Source

pub fn clear_oneshots(&mut self)

Stop and drop every placed one-shot (for scene transitions). One on its own track stops with it; a panned one needs telling.

Source

pub fn has_sound(&self, name: &str) -> bool

Check if a sound is already loaded

Source

pub fn set_filter_cutoff(&mut self, hz: f32)

Set the low-pass filter cutoff frequency (Hz). 20000 = fully open, lower = more muffled.
