Struct ProcGenCache 

Source 
pub struct ProcGenCache { /* private fields */ }
Expand description

In-memory LRU cache for procedural generation outputs.

Keyed by (ContentHash, Seed) — the content hash of the spec file and the generation seed. Evicts least-recently-used entries when the memory budget is exceeded.
