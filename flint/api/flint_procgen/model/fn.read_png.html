pub fn read_png(path: &Path, semantics: ChannelSemantics) -> Result<ImageData>
Expand description

Read a PNG back into an ImageData (RGBA8), so a written texture can be validated as it lies on disk. The file can’t say what the image means, so the caller names its semantics.
