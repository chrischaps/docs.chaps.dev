Module space_colonization 

Source
Expand description

Space colonization algorithm for organic branching structures.

Grows a tree graph toward a cloud of attraction points scattered within a crown volume (Runions et al., Modeling Trees with a Space Colonization Algorithm, 2007). Branches compete for the space they grow into, so the canopy fills its volume with adaptive branching density, which reads as more natural than an L-system for broadleaf crowns, roots and veins.

§Algorithm Overview

  1. Scatter attraction points inside a CrownVolume via rejection sampling (scatter_attraction_points)
  2. Grow a straight trunk from the root upward
  3. Each iteration, every attraction point pulls on its closest node within influence_distance; every pulled node grows one step_size toward the mean of its pulls
  4. Remove attraction points within kill_distance of a node
  5. Stop when no points remain, none can pull, or max_iterations is hit
  6. Assign branching depth and radii via the pipe model (r_parent^n = sum(r_child^n), da Vinci’s rule at n = 2)
  7. Convert the graph to Vec<BranchSegment> (branch_graph_to_segments), the same format the L-system produces

Each attraction point remembers its closest node; nodes are never removed, so an iteration only compares points against the nodes it just added. That keeps a step at O(points x new nodes) instead of O(points x all nodes).
