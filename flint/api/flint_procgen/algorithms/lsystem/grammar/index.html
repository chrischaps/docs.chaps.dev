Text L-systems: grammars written as strings, the way they are printed in The Algorithmic Beauty of Plants (Prusinkiewicz & Lindenmayer).

axiom:  X
rules:  X -> F+[[X]-X]-F[-FX]+X
        F -> FF

Grammar::expand rewrites the axiom; interpret walks the result with a 3D turtle and returns BranchSegments.

§Rules

A rule is "<symbol> -> <successor>". Several rules may share a predecessor, each with a weight: "F (0.33) -> F[+F]F". When a symbol has more than one rule, one is drawn per occurrence with probability proportional to its weight; a symbol with a single rule never touches the RNG, so deterministic grammars ignore the seed. → works as the arrow too, and whitespace is ignored everywhere.

A symbol written with arguments, F(2,0.5), is still the symbol F to the rewriter: a rule for F replaces it, arguments and all, and a symbol with no rule is copied as written.

§Turtle symbols

SymbolMeaningArgument
F, Gdraw forwardF(length) or F(length, radius)
fmove forward without drawingf(length)

/ / \roll clockwise / counter-clockwiseangle
|turn around (yaw 180°)
[ / ]push / pop the turtle
!thin the branch by radius_decay!(radius) sets it

Any other symbol (X, A, L…) only drives rewriting; the turtle skips it. Without arguments, a step is step_length long and the rotations use the configured angles.

Length and radius decay by nesting level: every [ multiplies the default step and the current radius by length_decay and radius_decay, and ] restores them. A branch’s children are shorter and thinner than it is however many rewriting passes produced them. Explicit arguments are used as written.
