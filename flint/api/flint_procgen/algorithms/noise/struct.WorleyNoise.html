Struct WorleyNoise 

Source 
pub struct WorleyNoise { /* private fields */ }
Expand description

Worley (cellular) noise: one jittered feature point per unit cell.

f1_f2 returns the raw cellular distances. As a NoiseSource it returns either a per-cell random value (the default, flat-shaded “cracked tile” look) or the signed F1 distance, both in [-1, 1]. Distances use any VoronoiMetric; the default is Euclidean.
