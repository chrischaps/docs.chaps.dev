Module noise 

Source
Expand description

Noise functions for procedural generation.

Provides a unified NoiseSource trait over Perlin, simplex, value and Worley (cellular) noise, plus a generic Fbm combinator for fractal Brownian motion. Everything here is implemented from scratch — no external noise crate — so the output is fully under our control and cannot drift when a dependency is upgraded. All types are Send + Sync for safe use in parallel generation pipelines.

Gradient noises (Perlin, simplex, value) are driven by a 256-entry PermutationTable shuffled by SeededRng; Worley feature points come from a stateless integer hash of the cell coordinates and the seed.

Functions§

crossfade_tiled
Make any field tile by cross-fading it with copies of itself shifted one period left, up, and both: at x = period_x the blend is exactly the x = 0 value. Averaging lowers the variance mid-tile, so the blend is divided by the RMS of its weights to keep the contrast even across the tile. Coordinates outside [0, period) are wrapped first. A period that isn’t positive leaves that axis unblended.
