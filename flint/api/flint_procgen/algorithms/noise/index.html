Module noise 

Source
Expand description

Noise functions for procedural generation.

Provides a unified NoiseSource trait over Perlin, OpenSimplex (patent-free simplex), and Worley (cellular) noise, plus a generic Fbm combinator for fractal Brownian motion. All types are Send + Sync for safe use in parallel generation pipelines.
