Module param_ui 

Source
Expand description

Schema-to-descriptor parser for procedural generator parameter UI.

Reads a generator’s param_schema() JSON Schema and produces a list of structured field descriptors (ParamFieldSpec) that a UI layer can consume directly — keeping JSON Schema interpretation out of the rendering code.

Functions§

lint_params
Report every key in params that the generator described by schema will silently ignore: keys missing from the schema (when it sets "additionalProperties": false), keys whose x-when condition the spec doesn’t meet, and keys the schema marks "deprecated": true. Returned in key order; empty means every key is read.
param_reference_markdown
A Markdown reference for one generator’s params, built from its schema: a table per condition (keys every spec may set first, then one table per x-when), each row the key, its type and range, its default and its description. The crate README’s catalog is this, for every built-in generator, and a test keeps the two equal.
parse_param_schema
Parse a generator’s JSON Schema into a list of UI field descriptors.
