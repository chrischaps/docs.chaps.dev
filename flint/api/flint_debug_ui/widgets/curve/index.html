Module curve 

Source
Expand description

Curve and gradient editors: a small egui painter widget over (t, value) keys in t ∈ [0, 1].

Interaction:

  • drag a key to move it (t clamped between its neighbours, value to the range)
  • double-click empty space to add a key
  • right-click a key to remove it (never below two keys)
  • hold Shift while dragging to lock t

Pure egui; no engine dependencies, so the particle editor, the scene inspector and game debug panels can all share it (ADR 0068).
