Expand description

Per-frame conducted-parameters snapshot (Phase 4 decision 4 / ADR 0020). Filled by the host (flint-player) from the music session every frame; neutral defaults when no session so scripts never branch on existence.

Fields§

§lean: [f64; 2]

Player lean and the chart’s lean target, both in [-1,1]².

§target: [f64; 2]§sway: [f64; 2]

Player sway (right stick; zeros under the prototype input map).

§pressure_l: f64

Trigger depths in [0,1] (zeros under the prototype input map).

§pressure_r: f64§cues: Vec<ConductedCue>

Cues fired this frame (empty most frames — ADR 0033).

§next_target: [f64; 2]

The next authored lean key’s value (ADR 0023); target when nothing is upcoming.

§next_target_beats: f64

Suite beats until that key’s anchor; 1e6 = nothing upcoming.

§next_pulse_beats: f64

Suite beats until the next unconsumed judgment window’s anchor beat (any kind); 1e6 = nothing upcoming. Lets the world telegraph that input is expected (P5 immediate-feedback pass).

§pulse_window_open: bool

True while that window is open right now (a press would land).

§coherence: f64§beat_phase: f64

0..1 within the current beat / bar (0 at the boundary).

§bar_phase: f64§bar: i64§beat: f64

Suite beats from zero, accumulated across tempo changes.

§section: String

Current section name; “” when none.

§pulses: Vec<ConductedPulse>

Pulses judged this frame (empty most frames).

§desaturate: f64

Ladder visual params (0 = clean).

§blur: f64§chromatic: f64§reassembly: f64

Reassembly progress: 1 = normal play, 0→1 while re-gathering.

§rewind: f64

Rewind interlude progress: 0 = not rewinding.

§no_input: bool§preroll: bool
