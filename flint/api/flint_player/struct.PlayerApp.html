Scene-authored hemisphere ambient (sky, ground); None = renderer default

§msaa_sample_count: u32

MSAA sample count for the scene renderer (1 = off, 4 = on; ADR 0058). Set from the –msaa CLI flag before the window/renderer exist.

§procgen_mode: ProcGenMode

When scene procgen assets are made (#32): during load, or behind placeholders on the frame-budgeted queue (--procgen-defer).

§render_scale: RenderScaleSetting

The scene’s render scale: a ceiling (fixed, and capped by pixel ratio) and whether to step under it to hold the frame rate (#122). The desktop’s default draws at the surface; a page’s caps DPR 1.5.

§procgen_disk_cache: bool

Keep procgen outputs on disk between runs (#181), in the project’s .flint/procgen-cache/ (or FLINT_PROCGEN_CACHE=<dir>; =0 turns it off). On by default natively; off for a bundle, whose files are not on the disk, and always off on the web.

§quality_overrides: String

key=value,... quality settings applied over msaa_sample_count, render_scale and the FLINT_SHADOW* switches at startup (FlintKart#55): --quality, the page’s ?quality=, an Android dev profile’s [quality]. Scripts change them later with set_quality.

§hold_at: Option<f64>

Game time, in seconds, at which the clock stops (it steps by zero from then on, and scripts keep running on a still world). With clock.frame_step it holds a page on an exact moment for a screenshot (#102, the web’s ?hold_at=); --screenshot-at is the desktop’s way.

§scene_diffuse_wrap: Option<f32>

Scene-authored diffuse terminator wrap; None = 0 = legacy shading

§scene_oren_nayar: Option<f32>§scene_sheen: Option<([f32; 3], f32)>§scene_camera: Option<CameraDef>§scene_post_process: Option<PostProcessDef>§scene_preload_audio: bool

[scene] preload_audio — false skips the blanket audio/ preload (silent scenes start instantly); audio_source + session stems unaffected. Set from the scene file before startup, like msaa.

§window_size: (u32, u32)

Initial window size in physical pixels (--width/--height). Ignored on Android, where the surface is the screen.

§capture: CaptureConfig

Screenshot capture driven by --screenshot / --screenshot-at / --screenshot-every / --exit-after. Captures the presented frame (scene + egui HUD) right before present().

pub fn add_extension(&mut self, extension: Box<dyn PlayerExtension>)

Install a game’s extension. Its script API is registered right away, so add extensions before the event loop starts; after that, scripts already compiled still see the new functions, because Rhai resolves calls when they run. See PlayerExtension for when each hook runs.

Source

pub fn projector(&self) -> Projector

A handle on the camera scripts’ world_to_screen uses, for native functions an extension registers (ADR 0087). Take it before add_extension and move it into the extension, whose register_script_api closures clone it. Called from a script, it answers with the camera this frame renders with, as world_to_screen does; from pre_update, last frame’s, like ExtensionCtx::camera.

Source

pub fn apply_scene_settings(&mut self, scene_file: &SceneFile)

Take the scene file’s player settings: audio preload, skybox, ambient and shading levers, camera and post-processing. Both entries (main.rs and the web’s flint_web.rs) call it after new.

pub fn enable_perf(&mut self, gpu: bool)

Record frame and phase times for a perf readout (the web page’s ?perf=1, #120). gpu also turns on the renderer’s GPU timing (ADR 0108) where the adapter has timestamps; it adds a few small submissions a frame, so ?perf=cpu leaves it off.

pub fn start_audio(&mut self) -> bool

Begin sound, from the user gesture that begins the game (#101). A browser gives no sound before one, so the web player runs silent until this is called from its Begin click; on the desktop the device opened at start and this does nothing new. Loops already in the scene start, and so does the scene’s music session if it was skipped for want of a device. Says whether there is sound.
