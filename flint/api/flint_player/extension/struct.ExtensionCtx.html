Expand description

What an extension can reach during pre_update.

Fields§

§world: &'a mut FlintWorld§clock: &'a GameClock

Already ticked for this frame.

§input: &'a InputState

This frame’s input, before scripts read it.

§camera: &'a Camera

Last frame’s camera; scripts and physics may move it later this frame.

§gpu: Option<ExtensionGpu<'a>>

The renderer and GPU handles, for uploading meshes and textures. None until the window and renderer exist.

§persist: &'a mut PersistentStore

The store scripts read and write with persist_get / persist_set (save/persist.toml; ADR 0080). Writes here are visible to scripts this frame, and join the player’s save: one second after a burst of changes, on scene transitions and on exit. Call PersistentStore::request_flush to save at the end of this frame instead. Scripts can read every key, so keep secrets out of it.

§audio: ExtensionAudio<'a>

The player’s audio: play sounds, load sounds made in memory, and set the mixer buses (ADR 0084). See ExtensionAudio.

§rays: Arc<RayScene>

The meshes uploaded as ray targets (MeshOptions::ray_target), where the last frame drew them (ADR 0105): cast a ray or a segment through it to find the first thing drawn along it. Empty until the first frame is drawn. Scripts cast through the same scene.

pub fn is_cursor_captured(&self) -> bool

Whether the cursor is captured now (ADR 0110), as scripts’ is_cursor_captured() reads it. While it is, input.mouse_position is the window centre and clicks skip egui.

Source

pub fn fire_event(&mut self, name: impl Into<String>, data: impl Into<Value>)

Fire a custom game event, as a script’s fire_event_data does.

It joins this frame’s events, so scripts’ on_event(name, data) receives it before their on_update runs this frame. Audio triggers see it too. A table data arrives in scripts as a map; anything else arrives as #{ value: data }.

ⓘ
let mut data = toml::Table::new();
data.insert("count".into(), 3.into());
ctx.fire_event("inventory_changed", data);
Source

pub fn attach_mesh(&mut self, entity: EntityId, mesh: &str) -> Result<()>

Draw the runtime mesh mesh at entity’s transform, by setting the entity’s model to { asset = mesh, runtime = true }. The mesh may be uploaded before or after (see ExtensionGpu::upload_mesh); until it exists the entity draws nothing. Any other model fields are kept.
