1//! Flint Render - wgpu-based renderer for visualizing scenes
2//!
3//! This crate provides a PBR 3D renderer for previewing Flint scenes,
4//! rendering entities as colored shapes or imported glTF models with
5//! physically-based Cook-Torrance shading. Supports GPU vertex skinning
6//! for skeletal animation.
