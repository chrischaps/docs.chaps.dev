1//! World-space lines drawn in the 3D frame with a depth test (ADR 0083).
2//!
3//! A `WorldLine` is a segment between two world points with a colour and a
4//! width in logical points. Scripts queue them with `draw_world_line`; the
5//! renderer projects them with the camera the frame renders with and draws
6//! them over the finished image, hidden wherever the scene's depth is nearer.
7//! Unlike `draw_line_3d`, which projects onto the HUD, a ring drawn round a
8//! model passes behind it.
9
10/// One depth-tested world-space segment.
11#[derive(Debug, Clone, Copy, PartialEq)]
12pub struct WorldLine {
13    /// Start, in world units.
14    pub a: [f32; 3],
15    /// End, in world units.
16    pub b: [f32; 3],
17    /// Display-space (sRGB) RGBA, the same space as the HUD's colours.
18    pub color: [f32; 4],
19    /// Width in logical points, the HUD's unit. Below one pixel the line
20    /// fades instead of thinning.
21    pub thickness: f32,
22}
