1//! AI-assisted procedural generation: agents that write and refine
2//! [`flint_procgen::ProcGenSpec`]s.
3//!
4//! Tool-time only. This crate is not a default workspace member and nothing
5//! in the player links it. `flint-cli` does, for `flint gen --ai-*` and
6//! `flint gen --refine`, and supplies the mesh [`Previewer`] this crate
7//! can't (it depends on `flint-procgen` only, not on `flint-render`). Build
8//! it alone with `cargo build -p flint-procgen-ai`.
9//!
10//! - [`ProcGenAgent`] is the object-safe trait every agent implements.
11//! - [`AnthropicAgent`] asks Claude through the Messages API, and holds
12//!   every reply to the generator's schema and an actual build before it
13//!   accepts it, sending failures back for another round. Its refine can
14//!   see what a spec builds (a [`Previewer`] draws meshes) and keeps
15//!   refining while the [`measure`]d distance to the reference falls.
16//! - [`MockAgent`] is a local, deterministic agent for tests and pipelines
17//!   with no network: its specs always fit the generator's param schema.
18//! - [`cost`] prices every call, keeps the append-only ledger at
19//!   `.flint/procgen_costs.json`, and enforces a cost ceiling before each
20//!   request ([`CostMeter`]).
21//! - [`schema`] checks and repairs a spec's params against that schema.
