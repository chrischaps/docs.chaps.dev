1//! Musical suite manifests, beatmap charts, tempo maps, and validation.
2//!
3//! This crate is the data-contract layer for rhythm-driven Flint games
4//! ("linear composition, adaptive playback"): a per-suite TOML manifest
5//! (tempo map, sections, re-entry points, fixed six-bus stem inventory) and a
6//! per-suite beatmap chart (continuous input curves, discrete pulses, scene
7//! cues), plus the validator that cross-checks both against each other and
8//! against the stem files on disk.
9//!
10//! The schema is pinned by golden fixtures in the game repository; when this
11//! code and those fixtures disagree, the fixtures are correct. Schema doc:
12//! `docs/schema/manifest-schema-v0.md` in the game repo.
