Flint in a browser (#94; async startup #99, bundles #98, docs/design/web.md).

The web twin of main.rs. Arguments come from the page’s query string instead of clap, and the player starts with winit’s spawn_app instead of the blocking run_app. PlayerApp then asks for its GPU device without blocking (player_app/web_startup.rs) and finishes starting up when it lands.

A game arrives as a bundle (flint bundle, flint_core::bundle): the page fetches it with a progress bar, installs its files as the vfs, and loads the scene the manifest names, exactly as the desktop reads a game folder. Its late bundles (audio) are fetched once the player is handed to the browser; when one lands the vfs grows and the player loads the sounds it couldn’t find at start.

Query string (all optional): game= a game on play.chaps.dev (#103): the bundle at games//.flintpack, which the site’s deploy packs bundle= a .flintpack, relative to the page (wins over game) scene= with bundle: a scene inside it instead of the manifest’s; without: a scene TOML fetched from (default: the first-light demo, which needs no other files) msaa=1|4 scene-pass MSAA (ADR 0058) scale=|auto the 3D scene’s render scale (#122). By default it is drawn at no more than DPR 1.5 (WEB_DPR_CAP) and the HUD at the full DPR; a number from 0.25 to 1 draws at that scale instead, whatever the DPR (scale=1 is native); auto keeps the cap and steps under it when frames run over budget for seconds quality=k=v,… quality settings over msaa and scale (FlintKart#55), as flint-player’s –quality: quality=shadow_cascades=1,ssao=0 (comma-separated; scripts change them with set_quality) width=, height= fix the canvas to this many CSS pixels instead of the page frame_step= step game time exactly s per frame (--frame-step) hold_at= stop game time at s seconds, for a screenshot of an exact moment (with frame_step; PlayerApp::hold_at) perf=1|cpu the perf readout in a corner (#120): frame times over the last 10 s, each phase’s CPU time, each pass’s GPU time where the adapter has timestamp-query (cpu leaves GPU timing off), and a line to copy fps=30|60|auto|native which refreshes are drawn (#140). A rate is drawn as a whole number of refreshes (30 is every other at 60 Hz, every fourth at 120); auto draws every refresh while the frames hold it and drops to the rate they do hold when they don’t; native draws every refresh unpaced. Default: auto where the primary pointer is a finger, native elsewhere loop=poll run winit’s loop flat out (ControlFlow::Poll), as before #121, to compare against; the default draws once per requestAnimationFrame

Build and serve from crates/flint-player: trunk serve # http://127.0.0.1:8080 trunk build –release # dist/, wasm-opt -Oz applied
