Module bind_cache 

Source
Expand description

Bind groups and uniform slots a frame used to make again every frame (#139). On the web each createBindGroup and writeBuffer crosses from wasm into JS and costs far more than it does natively, so what a frame binds is made once and kept for as long as what it binds.

A BindCache lives inside the thing whose resources its bind groups point at (the post-process chain’s PostProcessResources, rebuilt on every resize), so it is dropped with them and never binds a stale view. A bind group over something owned elsewhere carries that owner’s [gpu_id] in its key.

A [TransformArena] holds the per-draw transform uniforms of cached draws in pages of 256-byte slots: each draw’s bind group binds its own slot, and a frame uploads each page in one write instead of a write per draw. Slots never move, so a bind group made for one stays good until the slot is freed.
