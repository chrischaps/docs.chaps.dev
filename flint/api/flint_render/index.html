Flint Render - wgpu-based renderer for visualizing scenes

This crate provides a PBR 3D renderer for previewing Flint scenes, rendering entities as colored shapes or imported glTF models with physically-based Cook-Torrance shading. Supports GPU vertex skinning for skeletal animation.
