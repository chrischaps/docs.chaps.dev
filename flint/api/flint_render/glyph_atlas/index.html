Module glyph_atlas 

Source
Expand description

Glyph atlas: monospaced glyphs rasterized into one coverage texture, for the ASCII styles and any later text-based look (#264, epic #260).

A GlyphAtlas is a grid of equal cells, one glyph each, in an 8-bit coverage image (0 paper, 255 ink) with a one-pixel gutter round every cell so a filtered sample never bleeds into a neighbour. It comes from one of three sources:

  • the built-in 8x8 set (GlyphAtlas::builtin), drawn by hand for the engine in builtin_8x8.txt and free of any font licence;
  • a TTF/OTF rasterized at a pixel height (GlyphAtlas::from_ttf);
  • a bitmap grid image, one glyph per cell (GlyphAtlas::from_grid_image).

A GlyphSet adds what a style needs on top: named luminance ramps and the edge glyphs, read from a *.glyphs.toml (see set). Everything is read through flint_core::vfs, so a game bundle on the web serves it the same as the disk. GpuGlyphAtlas uploads an atlas as an R8Unorm texture.
