Module palette 

Source
Expand description

Colour palettes (#276): a short list of ink colours and a background, read from a *.palette.toml, for any style that wants a fixed set of colours (ASCII’s palette colour mode first).

# palettes/phosphor.palette.toml
match = "luminance"          # nearest (default) | luminance
background = "#020a04"       # the ground behind the inks (default black)
colors = ["#1f6e33", "#33b04d", "#4dff6e", "#b4ffc4"]

nearest gives each cell the ink closest to its own colour (a CGA screen); luminance lists the inks darkest first and picks one by the cell’s brightness alone (a one-colour phosphor tube). Colours are display (sRGB) values, #rrggbb or #rgb, at most MAX_COLORS.

A style names a palette as builtin names (BUILTIN_PALETTES), a bare name looked up as <dir>/palettes/<name>.palette.toml in the scene’s folder then its parent, or a .palette.toml path. Every read goes through the vfs.
