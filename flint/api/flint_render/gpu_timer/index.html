Module gpu_timer 

Source
Expand description

GPU time per pass, from timestamp queries (ADR 0108).

A GpuTimer brackets parts of a frame with timestamps written on the GPU, resolves them into a buffer at the end of the frame and reads it back a frame or more later without ever waiting, as the grass count is read (ADR 0092). Each bracket is a GpuScope: GpuTimer::begin and GpuTimer::end in one encoder, or GpuTimer::begin_submit and GpuTimer::end_submit around work spread over several submissions.

A timestamp is written by an empty compute pass carrying it, so only Features::TIMESTAMP_QUERY is needed, not timestamps inside encoders, and no pass descriptor changes. A scope measures from its first timestamp to its second on the queue’s clock: the GPU’s time on the work between them, plus any time the GPU sat idle waiting for the next submission inside the scope.

SceneRenderer owns one when timing is on and scopes its own phases; hosts add theirs through SceneRenderer::gpu_timer_mut.
