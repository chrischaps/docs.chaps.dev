GPU-instanced grass rendering pipeline

Two-pass system: compute shader places instances, render pass draws cross-quads.

Generate the shared cross-quad blade mesh. Returns (vertices, indices) for 3 intersecting quads at 60° intervals. Each quad has 7 vertices (4 segments + pointed tip).
