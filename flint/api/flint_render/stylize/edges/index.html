Module edges 

Source
Expand description

Shared geometry edges (#301): one edge texture a frame, for every style that asks for it.

The ASCII spike (#261, round 2) found that edges from the geometry give objects their definition: Sobels over the relative view distance and over normals rebuilt from depth, near side only. Pencil, ASCII and whatever comes next all want them, and each computing its own would pay for the 5x5 unprojection once per style. A style says needs: &[StyleNeed::Edges] in its descriptor instead; while any style that does is on, the framework draws this pass once, before the first stage runs, and every style reads the result from StyleFrame::edges.

The texture is the depth’s size (the scene’s, under a render scale), so an edge is one depth pixel wide; a display-stage style reads it by UV, like the depth and the mask. Rgba16Float:

channelwhat
rsilhouette strength: the relative-distance Sobel over PostProcessConfig::edge_depth, near side only
gcrease strength: the rebuilt-normal Sobel over PostProcessConfig::edge_normal, where the patch is one surface
bathe unit gradient across the edge, screen space (x right, y down): the silhouette’s where r >= 1, else the crease’s

A value of 1 is an edge at the shared thresholds. The thresholds are shared because the pass runs once; a style that wants more or fewer lines compares the strengths against a level of its own (r * k >= 1). The two pixels at each border are 0: there the patch clamps and the repeated positions make a degenerate normal.
