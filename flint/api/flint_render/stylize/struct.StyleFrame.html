Expand description

Everything a style may read in one frame.

Fields§

§device: &'a Device§queue: &'a Queue§config: &'a PostProcessConfig§descriptor: &'static StyleDescriptor§width: u32

The size of the input and output, in pixels.

§height: u32§format: TextureFormat

The input’s and output’s format.

§depth: &'a TextureView

The scene’s depth (single-sample; under a render scale, the scaled scene’s). Sample it by UV: at the display stage it is smaller than the output.

§depth_size: [u32; 2]

depth’s size in pixels, which a view doesn’t say: the scene’s, so smaller than width x height at the display stage under a render scale. The style mask is this size too.

§depth_owned: bool

Whether depth is the chain’s own, so bind groups over it may be kept (StyleFrame::depth_bind).

§camera: StyleCamera§mask: Option<&'a TextureView>

The entity style mask (#263): one style id a pixel (STYLE_MASK_FORMAT, texture_2d<u32>, 0 = unstyled), at the scene’s resolution like depth, so a display-stage style reads it by UV with textureLoad. Some whenever a style with uses_mask is on. It lives with the chain; bind it with mask_bind.

§style_ids: &'a StyleIds

Which id each style name has in mask.

§edges: Option<Arc<StyleTexture>>

The shared geometry edges (#301, edges says what the channels hold): EDGE_FORMAT, the depth’s size, read by UV with textureLoad. Some whenever a style that needs them is on; the framework draws them once, before the first stage, for every style that reads them. Bind it with edges_bind.

§linear_sampler: &'a Sampler

The chain’s linear, clamped sampler.

§time: f32

Seconds of game time, for animated styles.

§frame: u64

This frame’s number: one more than the last frame the renderer drew through the post chain. A style that keeps history from frame to frame (ASCII’s temporal stability, #277) trusts it only when the last frame it drew is frame - 1, so a frame drawn without it (the style switched off a while) starts it over.

§history_epoch: u64

Bumped by SceneRenderer::reset_style_history (a new scene, a camera cut): history from another epoch is not this picture’s past.

§pixels_per_point: f32

Physical pixels per logical point of the window (the OS scale factor). A style sized in points multiplies by it, so its cells keep their size on a high-DPI display. 1 headless unless asked.

§scene_dir: Option<&'a Path>

The scene’s folder, for styles that load files (a glyph set from fonts/), when the host knows it.
