Expand description

A registered style: what it is called, where it runs and how to make it.

Fields§

§name: &'static str

The name in [post_process.styles.<name>]; lowercase, no spaces.

§label: &'static str

What the F4 menu and --gpu-time call it.

§stage: StyleStage§params: &'static [StyleParam]

Parameters and their defaults, read with StyleFrame::param.

§options: &'static [StyleOption]

Named choices and their defaults, read with StyleFrame::option.

§enabled: Option<fn(&PostProcessConfig) -> bool>

When the style is on. None reads enabled from PostProcessConfig::styles; a style with fields of its own on PostProcessConfig (Kuwahara) reads those instead.

§uses_mask: bool

Whether the style reads the entity style mask (#263). While any such style is on, the renderer draws the mask each frame and hands it over as StyleFrame::mask; while none is, the mask isn’t made.

§needs: &'static [StyleNeed]

Framework-made inputs the style reads (#301). While any style that asks for one is on, the framework makes it once a frame for all of them: StyleNeed::Edges is StyleFrame::edges.

§hints: &'static [StyleHint]

How the F4 menu labels its settings (StyleHint); &[] is fine.

§component: Option<&'static str>

The component an entity takes this style with, its fields being the style’s parameters and options (ascii_style, #266). A style with one is per-entity: an entity carrying it (or a style_mask naming the style) switches the style on for that entity’s pixels alone, with no [post_process.styles] table, and the style reads each pixel’s settings from StyleFrame::variants by its mask id.

§create: fn(&StyleDevice<'_>) -> Box<dyn StylePass>

Build the style’s pipelines. May panic on a broken driver; the framework catches it.
