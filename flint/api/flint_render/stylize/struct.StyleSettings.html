pub fn from_tables(tables: &BTreeMap<String, Table>) -> (Self, Vec<String>)

Read a scene’s [post_process.styles] tables. A table switches its style on unless it says enabled = false; an option is a string, a parameter a number, and a colour (#315) an array of three numbers or a #rrggbb string (its channels may still be set one by one). Returns the settings and a warning for each name, key or value the registry doesn’t know.
