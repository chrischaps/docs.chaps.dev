flint_render::stylize

Module kit 

Source
Expand description

The building blocks most styles are made of: a full-screen triangle pipeline, the two bind group shapes the post chain uses, a uniform buffer and the pass that draws one triangle. With these a style is mostly its shader and its uniform struct.
