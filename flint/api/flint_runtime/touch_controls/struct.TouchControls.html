Screen size in physical pixels, pixels per logical point, and the safe-area insets in points (left, top, right, bottom).

Source

pub fn set_enabled(&mut self, enabled: bool)

Put the controls away (false) or bring them back (true). While away they hold no fingers and every touch reaches the game, but a finger still counts as seen, so they return already showing.

Source

pub fn enabled(&self) -> bool

Whether the game has the controls out (see Self::set_enabled).

Source

pub fn visible(&self) -> bool

Whether the controls are on screen now.

Source

pub fn note_touch(&mut self)

A real finger touched: the controls appear (in auto mode).

Source

pub fn note_other_device(&mut self)

A key or pad took over: the controls go, letting go of every finger.

Source

pub fn would_grab(&self, pos: (f64, f64)) -> bool

Whether a finger landing at pos (pixels) would be taken by a stick, button or the menu: the player keeps such a touch from egui.

Source

pub fn holds(&self, id: u64) -> bool

Whether finger id is held by a stick, button or the menu.

Source

pub fn touch_start(&mut self, id: u64, pos: (f64, f64)) -> bool

A finger landed. Returns true if a stick, button or the menu took it (it should then stay out of the game’s own touch list).

Source

pub fn touch_move(&mut self, id: u64, pos: (f64, f64)) -> (bool, (f64, f64))

A finger moved. Returns (claimed, look delta in mouse counts).

Source

pub fn touch_end(&mut self, id: u64) -> bool

A finger lifted or was cancelled. Returns true if a stick, button or the menu held it.

Source

pub fn action_value(&self, action: &str) -> Option<f32>

What the controls add to action now, if anything drives it: a held button reads 1, a stick direction its deflection that way, a stick axis its signed deflection.

Source

pub fn stick_value(&self, i: usize) -> [f32; 2]

Stick i’s deflection, x right and y up.

Source

pub fn widgets(&self) -> Vec<TouchWidget>

Every control, laid out in points, for the player to draw. Empty while hidden.

Source

pub fn opacity(&self) -> f32

Opacity the player should draw at.
