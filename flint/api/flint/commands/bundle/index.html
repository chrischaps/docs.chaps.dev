Module bundle 

Source
Expand description

flint bundle: pack a game folder into .flintpack files for the web player (#98; format in flint_core::bundle, docs/design/web.md).

flint bundle ../Float                  # dist/float.flintpack + dist/float.audio.flintpack
flint bundle ../Float --list           # every file, its size and its bundle
flint bundle . --out-dir web --scene scenes/title.scene.toml

The packer walks the game root, drops what a player never reads (the default excludes below, plus bundle.toml’s), and puts audio in a late bundle the web player fetches once the game is running: a browser can’t play sound before the first click anyway. Then it checks the bundle against itself before writing anything: every scene must load with its prefabs, every archetype must be in the bundled schemas, and every file a scene, prefab, particle effect, glyph set or script names must be packed. A missing file fails here rather than as a pink texture deep in play.

bundle.toml in the game root (every key optional):

name = "float"
scene = "scenes/float.scene.toml"
schemas = ["engine/schemas", "schemas"]
exclude = ["scenes/snap_*.scene.toml"]   # added to the defaults
include = []                             # wins over any exclude
[late]                                   # replaces the default { audio = [...] }
ambience = ["audio/ocean_loop.ogg"]     # fetched first: the sea at Begin
audio = ["audio/**"]

Late parts are fetched one after another in the order [late] lists them, and a file goes to the first part whose patterns match it. Put what is heard first in a small part of its own (#124).
