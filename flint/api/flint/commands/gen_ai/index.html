Module gen_ai 

Source
Expand description

The AI half of flint gen: build an agent, let it create, interpret or refine a spec before generation, and keep account of what it costs.

Everything the agent says goes to stderr, so stdout stays free for the generation summary or, with --print-spec, for the spec alone.
