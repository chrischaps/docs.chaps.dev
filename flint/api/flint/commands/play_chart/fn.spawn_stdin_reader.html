fn spawn_stdin_reader() -> Receiver<StdinCommand>
Expand description

Line-buffered stdin on its own thread: r + Enter reloads the coherence config, q + Enter quits, anything else (including bare Enter) is ignored — gamepad-to-keyboard mappers (Steam’s desktop layout maps A → Enter) spam stray keystrokes into the console during play, so every command needs a deliberate letter. Line-buffered beats raw mode here — no extra deps, no terminal-state cleanup, and a dev harness doesn’t need better.
