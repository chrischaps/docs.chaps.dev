Module play_chart 

Source
Expand description

Play a suite against its beatmap chart with live input capture: the Phase 2 dev harness. Thin front end over flint_music::ChartSession (the reactive loop itself lives in the library — ADR 0016): resolves the timing offsets, opens the session, spawns the 1 kHz capture thread, and prints the session’s notice lines.

Two front ends share one ChartSession: the console loop below, and the --window mode in play_chart_window (a focused window keeps gamepad-to-keyboard mappers from typing into the terminal, and carries the wordless visual cues).

spawn_stdin_reader 🔒
Line-buffered stdin on its own thread: r + Enter reloads the coherence config, q + Enter quits, anything else (including bare Enter) is ignored — gamepad-to-keyboard mappers (Steam’s desktop layout maps A → Enter) spam stray keystrokes into the console during play, so every command needs a deliberate letter. Line-buffered beats raw mode here — no extra deps, no terminal-state cleanup, and a dev harness doesn’t need better.
