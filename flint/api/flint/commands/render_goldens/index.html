Module render_goldens 

Source
Expand description

flint render-suite <file>.goldens.toml (#271): render a list of scenes with flint render, each with its own flags, and compare every image with a checked-in golden PNG. The suite fails when any case moves past its tolerance, so a change to the stylize framework (or anything under it) can’t silently shift a look.

[suite]
name = "stylize"
root = "../../../.."            # cases run from here (scene paths are relative to it)
width = 640
height = 360
args = ["--schemas", "schemas"] # before every case's own

[tolerance]                     # the defaults; a case may override any
level = 48                      # a pixel "differs" past this many levels (0-255, max channel)
share = 0.02                    # ...and the case fails when more than this share of pixels do
mean = 3.0                      # ...or when the mean difference passes this

[[case]]
name = "ascii-full-pbr"
scene = "demo/pbr_test.scene.toml"
golden = "ascii_pbr_test.png"   # beside the manifest; default "<name>.png"
args = ["--style", "ascii"]

Each case’s render, and a diff image when it fails, land in --out-dir (default: the system temp dir), with a report.json of every case’s numbers. --bless writes the renders over the goldens after a deliberate change; look at them before committing. Without a GPU adapter every case is skipped and the suite passes, unless --require-gpu.
