Module save 

Source
Expand description

Structure-preserving save for *.particles.toml.

When the emitter list has the same length, order and names as the saved copy, only the keys whose values changed are patched into the existing toml_edit document, so comments and formatting elsewhere survive. When emitters were added, removed, renamed or reordered the file is rewritten from the serialised effect (comments inside it are lost; the status line says so).
