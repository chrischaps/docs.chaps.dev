Module style_sheet 

Source
Expand description

A sweep’s contact sheet (#279): the same frame at several values of one setting, side by side, each labelled with what it was given. The letters are the ASCII style’s own built-in 8x8 glyphs (#264), so the sheet speaks in the same type the styles draw with.
