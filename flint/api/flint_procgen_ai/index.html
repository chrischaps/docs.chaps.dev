AI-assisted procedural generation: agents that write and refine [flint_procgen::ProcGenSpec]s.

Tool-time only. This crate is not a default workspace member and nothing in the player links it. flint-cli does, for flint gen --ai-* and flint gen --refine, and supplies the mesh Previewer this crate can’t (it depends on flint-procgen only, not on flint-render). Build it alone with cargo build -p flint-procgen-ai.

  • ProcGenAgent is the object-safe trait every agent implements.
  • AnthropicAgent asks Claude through the Messages API, and holds every reply to the generator’s schema and an actual build before it accepts it, sending failures back for another round. Its refine can see what a spec builds (a Previewer draws meshes) and keeps refining while the measured distance to the reference falls.
  • MockAgent is a local, deterministic agent for tests and pipelines with no network: its specs always fit the generator’s param schema.
  • cost prices every call, keeps the append-only ledger at .flint/procgen_costs.json, and enforces a cost ceiling before each request (CostMeter).
  • schema checks and repairs a spec’s params against that schema.
