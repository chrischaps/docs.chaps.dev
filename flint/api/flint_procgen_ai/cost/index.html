Module cost 

Source
Expand description

Cost tracking for AI calls: what each model charges, an append-only ledger of every call made, a report over it, and a CostMeter that sits in front of each request and refuses one the budget can’t cover.

The ledger is .flint/procgen_costs.json, one JSON object per line (JSON Lines), so a call is recorded by appending and nothing already written is ever rewritten. A line that doesn’t parse is skipped and counted, never fatal: the ledger is a record, not a dependency.

Prices are USD per million tokens, from Anthropic’s published rates (2026-10). A model not in the table is priced as the most expensive one and marked priced_as in the ledger, so an unknown model can make the budget too careful, never too loose.
