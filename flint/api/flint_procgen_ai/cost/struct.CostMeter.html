Struct CostMeter 

Source 
pub struct CostMeter { /* private fields */ }
Expand description

The cost-tracking middleware every API call goes through.

Before a request, CostMeter::admit prices its worst case (estimated input plus a full max_tokens reply) against what’s left of the ceiling: if it fits, it’s sent; if a smaller reply would fit, max_tokens is lowered so the ceiling still holds; if not even MIN_OUTPUT_TOKENS would, the call is refused with ProcGenAiError::CostCeiling. After a reply, CostMeter::record prices its real usage and appends it to the ledger.

pub fn record(&self, model: &str, usage: &Usage) -> f64

Record a call’s real usage: price it, add it to the total, append it to the ledger (a ledger that can’t be written is reported, not fatal: the call is already paid for), and warn once past WARN_FRACTION of the ceiling. Returns the call’s cost.
