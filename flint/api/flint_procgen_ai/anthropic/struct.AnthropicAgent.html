Expand description

A ProcGenAgent backed by the Claude Messages API.

Fields§

§max_tokens: u32

Output token ceiling per reply (thinking included).

§max_retries: u32

Extra attempts for a 429, 529, 5xx or network failure.

§refine_rounds: u32

Most refine rounds a measured refine runs: it renders each round’s result, and asks again while the distance to the reference falls. 1 is a single shot. Defaults to the config’s max_iterations.

pub fn refine_spec_reported( &self, spec: &ProcGenSpec, reference: Option<&[u8]>, ) -> Result<(ProcGenSpec, Report)>

ProcGenAgent::refine_spec, with the conversation’s Report.

With a reference, Claude also sees what the spec builds now beside it: a texture’s own pixels, or whatever the Previewer draws (a mesh render). When both images can be measured the refine is a loop: each round’s result is pictured and measured (measure::distance), and while the distance falls the new picture and numbers go back for another round, up to Self::refine_rounds. The first round that doesn’t get closer ends it, and the closest spec is returned: the input itself (report.kept == 0) when no round improved on it.
