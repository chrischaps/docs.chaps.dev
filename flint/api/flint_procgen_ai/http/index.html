Source
Expand description

The HTTP seam under crate::AnthropicAgent: a one-method Transport trait, the real ureq implementation, and the mapping from a Messages API response (or error) to Rust values.

Tests swap the transport for a scripted one, so every request the agent builds can be inspected and every response, good or broken, replayed.

Structs§

HttpRequest
An outgoing POST.
HttpResponse
A response with any status. Transports never turn a status into an error.
Reply
A successful Messages API reply.
ScriptedTransport
A Transport that replays canned responses in order and keeps every request it was sent: for testing code that drives an agent, with no network. Clones share the script and the record.
UreqTransport
The real transport: a blocking ureq agent with a long timeout, since a thinking model can take minutes on a hard spec.
Usage
Token counts from one response.

Transport
Sends a POST and returns whatever came back. Err only for failures where no response arrived (connection, TLS, timeout).
