flint_music

Module analysis 

Source
Expand description

Programmatic ears: pure analysis functions over rendered audio buffers.

These are the assertions the offline render harness makes available — per-tone envelopes (Goertzel), level-transition location, and click detection — so seam and scheduling checks are automated tests instead of listening tasks. All functions take interleaved stereo f32 as produced by crate::offline::render_offline, where index 0 = suite sample 0.

find_tone_transitions
Locate level transitions of one tone: suite samples where its windowed power first crosses below (drop) or above (rise) the midpoint between the local levels on either side. Resolution is one window.
goertzel_power
Power of a single frequency over [from, to) (suite samples), via the Goertzel algorithm on the mono sum. Cheap: one pass, no FFT.
max_step
Max per-channel sample-to-sample step — the cheap click/discontinuity detector. Scripted changes always ramp (>= a few ms), so any step above the content’s natural slew is a genuine discontinuity.
peak
Peak absolute sample value.
tone_envelope
Per-window power of one frequency along the whole buffer: element i covers suite samples [i*window, (i+1)*window).
