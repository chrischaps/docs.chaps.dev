flint_music::chart_session

Struct ChartSession 

Source 
pub struct ChartSession { /* private fields */ }
Expand description

Everything one live play-through owns, front-end agnostic. A front end calls ChartSession::tick at its own cadence (the audio clock is the master clock — ticking merely drains queues and advances judgment), plus ChartSession::reload_config / ChartSession::finish on its own input gestures.

impl ChartSession

Source

pub fn open(cfg: &ChartSessionConfig) -> Result<(Self, Vec<String>)>

Validate, start audio on a manager of our own, and assemble the whole reactive loop — the CLI path. Returns the session plus startup notice lines. The session has no input until the caller attaches a receiver via ChartSession::set_input.

Source

pub fn open_shared<B: Backend>( cfg: &ChartSessionConfig, manager: &mut AudioManager<B>, ) -> Result<(Self, Vec<String>)>

Same as ChartSession::open but the suite starts on a caller-owned manager (the player app’s device stream, ADR 0017). The borrow ends at start — the session keeps only kira handles, and the caller must keep the manager alive longer than the returned session.

Source

pub fn bridge(&self) -> ClockBridge

A clone of the clock bridge for the input producer to stamp events with (fed raw clock samples by every tick).

pub fn set_input( &mut self, rx: Receiver<InputEvent>, guard: Box<dyn Any + Send>, )

Attach the input source: the event receiver plus an opaque guard for the producer (dropped in finish before audio teardown).

Source

pub fn set_haptic_sink(&mut self, sink: Box<dyn FnMut(HapticEvent) + Send>)

Attach the haptic-event sink (ADR 0026): the front end’s adapter onto the capture thread’s rumble channel. Events arrive suite-addressed converted to raw clock samples already — the sink forwards them verbatim. Without a sink the driver never runs.

Source

pub fn haptics_active(&self) -> bool

Whether the resolved haptics config can emit anything — front ends use this to skip acquiring rumble hardware for inert sessions.

Source

pub fn tick(&mut self) -> Result<TickOutcome>

One iteration: pump the scheduler, feed the clock bridge, drain input into judgment, step coherence, log, and emit the per-bar status line.

Source

pub fn tick_with( &mut self, on_event: impl FnMut(&InputEvent), ) -> Result<TickOutcome>

ChartSession::tick with a per-event tap: on_event sees every drained input event, raw-stamped, before the timeline-offset remap. The player app down-samples this into its frame-quantized InputState (ADR 0018); the judge consumes the same events at full precision.

Source

pub fn reload_config(&mut self) -> Result<Vec<String>>

Source

pub fn stop_audio(&mut self, fade_ms: f64)

Stop every stem with an authored fade. Mandatory before dropping a shared-manager session: dropping kira handles does NOT stop sounds — the CLI path is only saved by its own manager dying with it.

Source

pub fn max_stem_skew(&self) -> f64

Max pairwise stem skew in seconds, straight from the mixer. Frame- cadence polling must expect the one-callback-buffer reporting transient (ADR 0017): re-read before believing a spike.

Source

pub fn visual_frame(&self) -> ConductedFrame

What the shader and scene bindings need this frame, straight from the conductor and the chart evaluator — never from judgment records (except the per-frame pulse buffer, ADR 0020).

Source

pub fn debug_force_fail(&mut self)

Debug-guide snapshot at the current position (ADR 0035) — dev overlays only, never the player-facing world. Debug: force the full reintegration (rewind → seam → reassembly) on the next tick, bypassing arming and the coherence hold. Dev surface only (the guide-frame contract); the seam machinery runs exactly as in a real fail. No-op while a seam is already in flight.

Source

pub fn guide_frame(&self, horizon_beats: f64) -> GuideFrame

Source

pub fn timeline_map(&self) -> &TimelineMap

The static suite-structure map for the debug timeline overlay, built once at open. Same dev-only contract as ChartSession::guide_frame.

Source

pub fn timeline_frame(&self) -> TimelineFrame

Per-frame debug-timeline snapshot: playhead + this-run seam/pulse history. Clones the histories — call only while an overlay is open (the guide-frame cost model).

Source

pub fn finish(self) -> Result<Vec<String>>

Tear down in order: input producer first, then judgment bookkeeping, then (by drop) the audio handles and any owned manager. On a shared manager, call ChartSession::stop_audio first — handles dropping does not stop sounds. Returns the summary notice lines.
