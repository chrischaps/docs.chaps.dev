Debug-timeline data (ADR 0037): the static suite map plus this-run history marks that the player’s Manifest Map panel draws. Dev surface only, never the player-facing world (the no-gamified-UI rule). Retained histories are written by ChartCore and read by ChartSession::timeline_frame — no deterministic path reads them.
