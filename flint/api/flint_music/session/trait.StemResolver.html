Expand description

Provides each bus’s sound data. FileStems is the real implementation; tests provide synthesized stems so tempo-change suites need no audio files.

fn load_alternate( &self, _bus: &str, _file: &str, ) -> Result<Option<StaticSoundData>>

A degraded alternate’s stem (ADR 0032). Default Ok(None): resolvers that don’t provide alternates leave them silently absent (the session warns), so test resolvers stay one-method.
