Soba Documentation

volca fm

Korg · synth, 3 voices · channel 1

Korg's original 2016 three-voice, six-operator digital FM synthesizer in a volca, with a step sequencer and arpeggiator.

From the maker's chart: KORG volca fm MIDI Implementation Rev. 1.01 (2016.4.07) and volca fm MIDI Implementation Chart Ver. 1.01 (2016.04.07, Model: volca fm), plus volca fm Owner's Manual (volca_fm_OM_EFGSCJ5), https://www.korg.com/us/support/download/product/0/558/

Before you play

The volca fm has a MIDI In only (no MIDI Out), and takes no Program Change. The manual does not state the factory MIDI channel (channel 1 is assumed): set it by holding MEMORY while powering on and pressing keyboard button 1-16. Hold FUNC while powering on and set global parameter 7 'MIDI RX ShortMessage' to On (the factory default), or notes, CCs and pitch bend are ignored; clock, Start and Stop are followed only while parameter 6 'MIDI Clock Src' is Auto (the default). Transpose steps shown apply when 'TRANSPOSE NOTE' is On; with it Off, CC 40 gives octave-range transposition of -36 to +36 semitones instead. Modulator/Carrier Attack and Decay run -63 to +63 around the voice's own setting (64 is no change). Korg's hex and decimal columns disagree in a few of the step tables, so Soba sends each step from the middle of its band, inside it whichever column is right.
